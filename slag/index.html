slag bash orchestrator

Terminal-UI Task Management System

Usage:

$ slag forge           # Start new task
$ slag heat <ingot>    # Work on specific ingot
$ slag status          # Show all ingots
$ slag proof <ingot>   # Test ingot completion

Ingot Status:

Field Semantics:

:id
Unique ingot identifier (e.g., "i1", "i2")
:status
Current state: ore (not started), molten (in progress), forged (complete), cracked (failed)
:solo
Boolean - can work independently (t) or needs dependencies (nil)
:grade
Complexity level: 1 (simple), 2 (moderate), 3 (complex)
:heat
Current attempt number
:max
Maximum attempts allowed before abandoning
:proof
Shell command to verify completion
:work
Description of the task to complete
